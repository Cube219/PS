# 풀이

* 각 학생마다 $V_i+P_i+S_i$를 기준으로 정렬하고, 이를 $V_0 + P_0 + S_0$ 보다 작거나 같은 학생들 중 $M-1$명 을 크기 순서대로 뽑으면 된다.
