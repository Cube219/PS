# 풀이

* 페이지 사이를 가로로 찍을 수 없다는 점을 생각해야 한다.
* 그러면, 먼저 왼쪽 끝이 짝수 / 오른쪽 끝이 홀수인 경우 세로로 찍고, 남은 공간을 가로로 찍으면 된다.
